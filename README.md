# Sistema de Arrendamiento de Espacios de Trabajo

##  Descripción

Aplicación web para la gestión de reservas de espacios de trabajo (coworking), que permite visualizar disponibilidad, consultar precios y realizar reservas de forma sencilla.

---

## Objetivo

Permitir a los usuarios consultar espacios disponibles y realizar reservas de manera rápida y clara.

---

## Funcionalidades

* Visualización de catálogo de espacios (3 espacios)
* Visualización de precios
* Consulta de disponibilidad
* Creación de reservas
* Cancelación de reservas
* Notificación de confirmación

---

## Tecnologías utilizadas

* HTML
* CSS
* JavaScript
